# Sea Credit website and client portal

Responsive, buildless HTML/CSS/JavaScript concept. Serve `dist/` with any static web server. The landing page links to `#portal` for the demo client area.

Includes an illustrative calculator, demo application, loan overview and filters, repayment schedule, profile editing in memory, simulated card replacement, CSV statement and text summary downloads. No personal information from the supplied screenshots is reproduced.

This is a frontend prototype, not a production lending platform. Authentication, loan underwriting, actual rates and fees, KYC, payment processing, document storage and account APIs are not connected. No form sends information to Sea Credit. Demo state is held in browser memory and resets on reload.

Brand direction is provisional; the linked LinkedIn page could not be fetched. Company positioning was informed by https://vc4a.com/ventures/sea-credit-ltd/ and https://fi.co/insight/founder-institute-lagos-produces-17-new-technology-companies . The illustration is a remotely hosted Unsplash photograph; fonts load from Google Fonts. Confirm brand assets, terms, privacy copy and production integrations before public release.
